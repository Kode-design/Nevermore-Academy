# Wednesday: The Nightshade Secret

A fan-made top-down adventure game set in the Nevermore Academy universe. Play as Wednesday Addams and solve the mystery of the Nightshade Library.

## Features
- **Play as Wednesday:** Explore the library with her signature stoic demeanor.
- **Retro Aesthetic:** Pixel-art style graphics.
- **Interactive Mystery:** Talk to Enid, search for clues, and unlock secrets.

## How to Play
1.  Clone the repository.
2.  Since this is a web-based game using Phaser 3, it requires a local web server to run (due to browser security policies regarding loading assets).
3.  Run the following command in the project root:
    ```bash
    python3 -m http.server
    ```
4.  Open your browser and navigate to `http://localhost:8000`.

## Controls
- **WASD / Arrow Keys:** Move
- **Space / E:** Interact
