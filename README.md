# Wednesday: The Nightshade Secret

A 2D pixelated RPG set in the Wednesday Addams universe.

## Story
Wednesday Addams has taken a part-time job at the Weathervane Diner to conduct "research." However, a visit from a werewolf biker gang and a mysterious, helmeted figure shrouded in shadow pulls her into a new mystery.

## Controls
- **Arrow Keys:** Move Wednesday.
- **Space:** Interact / Advance Dialogue.
- **T:** Switch to Thing (Coming Soon).

## Development
This game is built with [Phaser 3](https://phaser.io/).

### Running Locally
1. Clone the repository.
2. Run a local web server in the root directory:
   ```bash
   python3 -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.

## Assets
- Placeholder pixel art assets are used for characters.
- Dialogue system is implemented in `src/scenes/UIScene.js`.
