# Wednesday's Solitude

A web-based survival game set in the world of Nevermore Academy. You play as Wednesday Addams, trying to avoid social interactions while collecting pages of the Nightshade Society's journal.

## Game Mechanics

- **Player:** Wednesday Addams.
- **Goal:** Collect all 10 pages of the journal.
- **Hazards:** Enid clones (and other students) who want to socialize. Touching them drains your "Social Battery".
- **Ability:** Press `SPACE` to throw Thing. Thing will stun enemies for a short duration.
- **Controls:**
    - `WASD` or `Arrow Keys` to move.
    - `SPACE` to throw Thing.

## Tech Stack

- **Engine:** [Phaser 3](https://phaser.io/)
- **Build Tool:** [Vite](https://vitejs.dev/)

## How to Run

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start the Development Server:**
   ```bash
   npm run dev
   ```

3. **Open the Game:**
   Open your browser and navigate to the URL shown in the terminal (usually `http://localhost:5173`).
