# Nevermore Academy

A collaborative playground for building out **Morrowfell Academy**, an isometric 2D, party-based RPG focused on narrative agency, tactical combat, and free-form character builds set within a gothic boarding school for the supernatural.

## Getting Started
- Explore the living [game design scaffold](docs/game_design.md) for systems, story pillars, and early content beats.
- Use this repository as the foundation for prototyping art, combat logic, and narrative tooling.

## Contributing
Feel free to extend the design, add prototypes, or flesh out tooling. Follow standard Git workflows and document notable additions.
