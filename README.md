# Nevermore Academy

A collaborative playground for building out **Morrowfell Academy**, an isometric 2D, party-based RPG focused on narrative agency, tactical combat, and free-form character builds set within a gothic boarding school for the supernatural.

## Play the Vertical Slice

The repository now ships with a browser-playable prototype that covers:

- **Character creation** with species, backgrounds, aspirations, and attribute allocation.
- **Isometric exploration** of the Fell Keep tramway, including Veil Heat management and branching micro-events.
- **Turn-based combat** against the Tram Wight, featuring companion support and species-driven signature techniques.

### Run locally

```bash
npm install
npm run dev
```

Open the printed URL (default `http://localhost:5173`) in a modern browser. Use **WASD / arrow keys** to move during exploration and click the action buttons during combat.
